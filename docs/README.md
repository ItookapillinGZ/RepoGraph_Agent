# Documentation map

## Product documentation

- `ARCHITECTURE.md`: current v1 system boundaries and responsibility split
- `DEMO.md`: two-, five-, and ten-minute demonstrations
- `EVALUATION.md`: authoritative H2 interpretation and limitations
- `PORTFOLIO.md`: summaries, resume bullets, interview answers, and tradeoffs
- `PROJECT_INVENTORY.md`: functional repository map
- `SANDBOX_SECURITY.md`: detailed Docker invariants and acceptance evidence
- `OBSERVABILITY.md`: tracing and artifact lineage
- `REPLAY.md`: deterministic verification replay

Top-level `SECURITY.md` is the short product security overview. Top-level
`README.md` is the canonical setup and quickstart.

## Preserved historical/acceptance notes

- `H1_2_AUDIT.md`
- `STUDIO_ACCEPTANCE.md`
- `SWEBENCH_EVALUATION.md`

These files preserve development and acceptance context. They are not the
canonical installation path and are not rewritten to make historical outcomes
look more favorable. Follow the product documents above for current commands.
